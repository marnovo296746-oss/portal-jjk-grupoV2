# Portal JJK v2

Portal para comunidade de Jujutsu Kaisen: cadastro pendente, login, jornal, membros e painel da Era Heian.

## Render + PostgreSQL
Web Service: Node, Build `npm install`, Start `npm start`, Branch `main`, Root vazio.
Variáveis: `DATABASE_URL` = Internal Database URL do PostgreSQL; `SESSION_SECRET` = segredo longo aleatório.
O primeiro cadastro vira administrador. Os demais ficam pendentes até aprovação.
